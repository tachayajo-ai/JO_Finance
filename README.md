# LIACAM Retirements

เครื่องคำนวณเงินลงทุนเพื่อการเกษียณ (ไฟล์เดียว ไม่ต้องติดตั้ง) เปิด `index.html` ในเบราว์เซอร์ได้เลย

- Input: ปี พ.ศ., อายุ, ทุนตั้งต้น, ลงทุนรายเดือน, % เพิ่มต่อปี, ผลตอบแทนก่อน/หลังเกษียณ, เงินเฟ้อ, ค่าใช้จ่าย, รายได้อื่น
- ข้าราชการ: สมาชิก กบข./ระบบเดิม, บำนาญ vs บำเหน็จ, เงินเดือน+เลื่อนขั้น+เพดาน, เวลาราชการ, เงิน กบข. (สะสม/สมทบ 3%/ชดเชย 2%), บำเหน็จดำรงชีพ
- Output: เงินสะสม ณ เกษียณ, เงินที่ต้องมี, ส่วนขาด/เกิน, เงินหมดตอนอายุ/พ.ศ., เงินที่ควรลงทุนต่อเดือน, Sensitivity ±2% ผลตอบแทน, กราฟ และตารางรายปี (คัดลอกไป Excel ได้)

โครงสร้าง
- `src/retirement-calculator.html` — ต้นฉบับ (ใช้ publish เป็น Artifact)
- `index.html` — เวอร์ชันเปิดใช้งานตรง สร้างจากต้นฉบับโดยครอบ `<!doctype html>`
- ภาษี: คำนวณภาษีเงินได้ปีปัจจุบัน + สิทธิลดหย่อน RMF / Thai ESG / SSF (SSF หมดสิทธิตั้งแต่ปีภาษี 2568), เพดานกลุ่มเกษียณ 500,000, เลือกนำภาษีที่ลดได้ไปลงทุนต่อ
- ปุ่มสลับธีมมืด/สว่าง (จำค่าไว้ในเบราว์เซอร์)
- ระดับตำแหน่งข้าราชการพลเรือนสามัญ (ทั่วไป/วิชาการ/อำนวยการ/บริหาร) → เพดานเงินเดือนตามบัญชีท้าย พ.ร.บ.ฯ 2558, เลื่อนระดับตามปีที่คาด, ปุ่มเลือกบำนาญ/บำเหน็จ และตารางเปรียบเทียบ
- ตัวเลือกสิทธิเงินเดือนสูงกว่าขั้นสูง (ม.50/1): เต็มขั้นแล้วขึ้นต่อได้ถึงเพดานระดับถัดไปในประเภทเดียวกัน
- โลโก้ต้นกล้าบนกองเหรียญ: `assets/logo.svg` (favicon/โลโก้หัวแอป), `assets/apple-touch-icon.png` (ไอคอนหน้าจอหลัก 180×180) — ฝังในไฟล์แอปเป็น data URI แล้ว
