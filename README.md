# JO Finance — แผนเงินเกษียณ

เครื่องคำนวณเงินลงทุนเพื่อการเกษียณ (ไฟล์เดียว ไม่ต้องติดตั้ง) เปิด `index.html` ในเบราว์เซอร์ได้เลย

- Input: ปี พ.ศ., อายุ, ทุนตั้งต้น, ลงทุนรายเดือน, % เพิ่มต่อปี, ผลตอบแทนก่อน/หลังเกษียณ, เงินเฟ้อ, ค่าใช้จ่าย, รายได้อื่น
- ข้าราชการ: สมาชิก กบข./ระบบเดิม, บำนาญ vs บำเหน็จ, เงินเดือน+เลื่อนขั้น+เพดาน, เวลาราชการ, เงิน กบข. (สะสม/สมทบ 3%/ชดเชย 2%), บำเหน็จดำรงชีพ
- Output: เงินสะสม ณ เกษียณ, เงินที่ต้องมี, ส่วนขาด/เกิน, เงินหมดตอนอายุ/พ.ศ., เงินที่ควรลงทุนต่อเดือน, Sensitivity ±2% ผลตอบแทน, กราฟ และตารางรายปี (คัดลอกไป Excel ได้)

โครงสร้าง
- `src/retirement-calculator.html` — ต้นฉบับ (ใช้ publish เป็น Artifact)
- `index.html` — เวอร์ชันเปิดใช้งานตรง สร้างจากต้นฉบับโดยครอบ `<!doctype html>`
